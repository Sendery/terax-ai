# Pi-Terax v0.9.0-dev.22

Publicado el 19 de noviembre de 2026. Parte de dev.21. Se empaqueta igual: Pi-Terax.app con el identificador habitual app.crynta.terax, motor Ghostty y compilación de desarrollo firmada con la identidad local.

## Reader: lectura guiada con voz

Una pestaña nueva que lee textos largos en voz alta con la voz local y resalta cada palabra mientras suena. Es la idea de GhostReader adaptada a Terax.

- **Lienzo de lectura.** Columna de libro de unos 72 caracteres. El texto pendiente aparece atenuado, la frase activa iluminada, la palabra que suena en ámbar y lo ya leído algo apagado. Un ▶ verde en el margen marca dónde se dejó la lectura.
- **Interacción.** Clic en una palabra para leer desde ahí. Atajos del documento:
  - Espacio para reproducir o pausar.
  - ← → por frases y ⇧← ⇧→ de 10 en 10 segundos.
  - j k para desplazarse libremente, con un botón para volver al punto de lectura.
  - w b { } para mover el cursor por palabras o párrafos, y Enter para leer desde él.
  - c para centrar, m, p y P para los cortes, [ ] Tab para saltar entre ellos y + - para la velocidad.
  - f para los controles flotantes, e para exportar y q para guardar y cerrar.
- **Controles.** Barra inferior con transporte, tiempo, barra de progreso, velocidad de 0.75x a 2.5x, voz por documento y cortes. Si la lectura sigue en otra pestaña, los controles flotan sobre el espacio de trabajo.
- **Audio por segmentos.** Cada frase, título, elemento de lista o fila de tabla se sintetiza por separado. El resaltado se estima dentro de cada frase corta a partir de la duración real del clip; no hace falta que el motor dé tiempos ni detectar cortes en el audio. El código se muestra pero no se lee, y los enlaces sueltos se saltan.
- **Cortes guionizados.**
  - Marcadores, con un modo estudio que se para en cada uno.
  - Pausas de 1,5 s por defecto.
  - Paradas.
  - Se pueden escribir en el propio texto: `[pause: 2s]`, `[pausa: 800ms]` o `[stop]`.
- **Almacenamiento local.** Cada documento vive en `reader/<id>/`:
  - `source.txt`;
  - un `manifest.json` con la posición, los cortes y los tiempos por palabra;
  - un WAV por segmento y voz;
  - las exportaciones.

  Al reabrir un texto se retoma en la última palabra. Lo ya sintetizado se reproduce aunque el motor de voz esté parado.
- **Exportación.** Un único WAV con las pausas, más capítulos en JSON y una hoja CUE a partir de los títulos y los marcadores.
- **Entradas:**
  - `terax-read fichero.md` y `cat x | terax-read` desde los terminales de Terax;
  - «Open in Reader» en el menú contextual de un terminal;
  - en la paleta: abrir la selección, abrir el fichero activo y retomar el último documento.

## Agentes

Seis comandos nuevos, presentes en el registro, el MCP, la extensión Pi-Terax, la lista permitida del puente y las instrucciones del agente:

| Comando | MCP |
| --- | --- |
| `reader.open` | `terax_speak open_reader` |
| `reader.list` | `terax_inspect list_reader_documents` |
| `reader.state` | `terax_inspect reader_state` |
| `reader.control` | `terax_speak control_reader` |
| `reader.mark` | `terax_speak mark_reader` |
| `reader.export` | `terax_speak export_reader` |

## Limitaciones

- **Síntesis real sin probar.** En la máquina de pruebas no hay ningún motor de voz instalado. Para escuchar algo hay que instalar Kokoro en Ajustes, Voz.
- **Solo WAV.** No se exporta a MP3 ni a M4B.
- **El idioma solo elige la voz por defecto.** Se puede fijar una voz para cada documento en los controles.
- **Plataforma.** Solo Apple Silicon. Compilación de desarrollo sin notarización ni actualización automática.
